# AI 辅助

## 功能准入

目标：解释已经选定的资源和运行结果，不替用户选择、修改或 Apply。五项能力共享设备本地总开关与分项开关。全部手动触发，不执行外部内容，不自动重试，不同步开关、凭据或分析缓存。

所有 Agent 可分析 Profile 意图；Compare 仅分析已完成或不完整的已保存报告，不增加 Runner 能力。重复版本仅分析当前明确选中的版本预览，不读取任意来源路径。

组件映射：开关 -> Switch；设置行 -> SettingsPreferenceRow；动作 -> Button / ActionMenuItem；分析 -> Notice / ResourcePanelToolbar；详情 -> SyntaxCodePreview；窗口 -> ModalFrame / DialogHeader / DialogBody / DialogFooter / useModalDialog。页面只新增内容排列，不定义另一套控件。五项能力位于 Settings 的 AI 辅助页签，不混入 Skills 设置。额度说明复用 InfoTip。

## 状态与边界

关闭隐藏生成入口，后端同时拒绝请求；关闭会取消在途请求并停止队列。原结果和普通标签保留。总开关重开恢复子项选择。配置损坏时请求失败关闭，不回退为允许发送。

生成前确认服务、模型、发送内容和额度。以实际内容、语言及规则版本定位缓存；重新生成失败保留旧结果；输入变动重新预览，不后台计费。只对提供的证据作结论，不宣称安全认证、稳定优劣或测试成功。取消不能退还供应商已经消耗的额度。

Profile 读取已保存有效指令和启用的 Library Skills，尊重 Group、全局禁用和资源模式。未接管的 Agent 内容不读取，并注明范围。MCP 仅发送启用策略，不发送原生定义、凭据和环境变量。已知问题独立列出，不交给 AI 猜测。

Compare 保留失败、不完整、缺失指标事实；单次运行不能证明 Profile 更好。重复 Skill 不自动选择保留版本。分析只写本地缓存，不改变资源及 Apply 状态。

## 必须验证

总/分开关持久化、关闭零请求及取消；手动确认；内容缓存与过期；失败保留；非法证据拒绝；隐私白名单；正常管理动作不依赖 AI；中英繁体多尺寸、最大化、局部错误及长文本可读。

## 审查修复契约

产品：面向轻度与重度 Agent 用户的本地桌面环境管理器，以现有紧凑控件和只读分析为边界。操作风险 9/10、频率 6/10、信息密度 8/10、视觉表达 3/10、动效 2/10。避免新增导航、隐式计费、跨对象结论、假完整分析、页面自绘按钮。

核心任务 -> 让用户理解环境差异 -> 若用截断或缓存隐藏事实则损失判断可靠性 -> 保留完整身份指纹，明确实际发送范围。
分析意图 -> 未配置/输入过期/缓存损坏分支 -> 只写服务配置或分析缓存 -> 取消不改资源，失败保留原结果，坏缓存成功重建前另存原始字节。

症状类别与负责层：结果身份归 Renderer；序列化字节预算、截断范围、缓存恢复归分析服务；设置入口复用 AIServiceForm / TextField / Notice / Button；弹窗身份复用 DialogHeader；资源操作占位归 ToolbarOverflowMenu 和共享 patterns 样式，页面仅分配操作列。

范围：Profile、Compare、重复导入、Local Skills，及 Profiles/Workspaces 共用 SkillsEditor。布局仍为原侧栏、页头、单对象区或列表详情；不调整导航或滚动所有权。对象身份优先，次为范围/异常，最后是可执行动作；不增加装饰动画。

- 切换对象不得显示前一对象结果；同对象输入变化可以保留旧结果，但预览失败时也必须标明已过期。
- 预算以最终 UTF-8 JSON 字节为准，包含标签和封装；Renderer 不预先裁掉文件；缓存指纹包含全部文件变化。显示包含、截断、省略数量。
- 分析缓存损坏不阻止预览。只有用户确认且生成成功后才重建，保留原文件供排查；不改 Profile、Library、Agent。
- 服务未配置时在原分析上下文内复用配置表单，保存后回到确认，不直接调用。设置读取失败提示不得藏在折叠区。
- Profile 分析标题显示 Profile 名称及 Agent；Group、成员和普通 Skill 开关同列，缺少菜单保留无交互占位。
- 证据：对象切换及失败 Renderer 测试、中文/转义/多文件输入预算与坏缓存主进程测试、三尺寸开关对齐 Electron 测试、三语言分析弹窗和共享设置截图。发布包兼容另行验证。
