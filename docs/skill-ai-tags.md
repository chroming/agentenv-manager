# AI 标签建议

## 产品契约

目标是按适用任务找到 Skill，不引入新的分类或分组体系。所有标签共用一套筛选词表，但区分固定标签和 AI 标签。不修改 SKILL.md、源目录、Agent 或 Profile，不改变待 Apply 状态。

- `tags` 保存全部标签，`aiTags` 只记录其中来自已确认 AI 建议的标签。旧数据没有来源记录，全部视为固定标签，不从历史建议反推。
- 保存新建议时，替换之前的 AI 标签，保留最新的固定标签。固定标签与建议重名时固定优先；建议窗口自行输入的标签也是固定标签，即使与模型建议重名。空建议允许清除旧 AI 标签，不删除固定标签。
- 普通编辑保留未删除标签的来源；更新、合并和配置同步保留来源，合并重名标签时固定优先。列表用小图标和悬浮提示区别 AI 标签，编辑窗口分组展示；筛选不拆成两套。
- 编辑窗口可将 AI 标签转为固定标签，点击保存才持久化，取消不改原数据。仅改变标签归属也属于有效修改；未来重新生成不覆盖固定标签。
- 重新生成保留尚未保存的固定标签草稿。合并建议后超限不截断草稿，允许逐个移除标签直到满足上限；保存前仍严格校验。
- 服务未配置时，在当前窗口复用 AIServiceForm 完成配置，保留选择和标签草稿。保存配置不自动生成或发送 Skill 内容，仍需用户点击生成。

- 单项入口在编辑标签窗口，批量入口在 Skills 工具栏更多菜单。共用 SkillTagSuggestionsDialog，批量默认选择当前筛选范围内没有标签的已导入项。
- 每次打开批量窗口都使用当前列表的筛选范围，不沿用上次窗口的范围。All 是明确状态，包含启用和禁用项；Updates 只包含可更新项，其他搜索和筛选条件仍然生效。
- 打开、检查更新、导入、后台任务只允许读取缓存，绝不调用模型。点击建议标签直接生成，不再增加二次确认；每个 Skill 最多一次请求，无自动重试或切换服务。保存标签仍是独立操作。
- 复用 AI 服务配置、安全存储和 AIJsonClient。AI 没有工具，不执行 Skill，不跟随链接。只发送名称、描述和标签词表，不发送正文或本地路径。优先沿用全库相关固定标签，新标签参考其语言、大小写和粒度，不强行套用不相关标签。尽力脱敏，不承诺发现全部敏感信息。
- 优先复用原标签名称，建议 2–5 个有辨识度的任务标签；没有依据可以返回空列表。新标签按界面语言生成，现有词表不翻译、不强制合并语义相似词，不提供安全认证。
- 保留每 Skill 最多 12 标签、每标签 32 字符以及已有规范化规则，按替换后的总数检查上限，超过上限必须精简，不截断保存。建议可删除、手动补充。
- 缓存以 Skill ID、完整 SKILL.md 内容哈希、词表哈希、语言和分析规则版本定位，按设备保存，独立于可同步标签元数据。重复打开不重新计费；明确重新生成才覆盖缓存，失败保留之前结果。
- SKILL.md 仍在本地校验和计算哈希，超过 1 MB 拒绝读取；请求仅包含名称、描述前 12000 字符及固定/全部词表各前 500 项，截断标记为部分输入。复用 90 秒超时、96 KB 输入与 128 KB 响应上限，不自动分块增加费用。
- 列表标签使用独立 Tags 列，不另起一行。只显示能完整容纳的标签，剩余收进 +N 菜单；标签及菜单项可点击筛选，长标签不改变行高。编辑保留在原菜单入口。
- 保存走现有 mutation coordinator；每项重新确认 SKILL.md 内容哈希，读取当前标签后替换 AI 部分，防止覆盖期间新增的人工标签。内容变化或已删除时局部报错，不影响其他项。

## 功能准入与组件

所有 Agent 无关：Library 元数据操作，本地与在线导入项都支持，来源中未导入候选不参与。禁用项只有用户筛选或选择后才参与。

动作 -> ToolbarOverflowMenu、Button、IconButton；选择 -> ChoiceInput；标签 -> TagChip、SkillTagList；补充 -> TextField；状态 -> InteractiveStatus、Notice；窗口 -> ModalFrame、DialogHeader/Body/Footer、useModalDialog；布局 -> ResourcePanelToolbar，支持最大化。

idle 只读缓存；working 逐项动画、可停止；success 建议就绪仍未保存；error 局部原因、单项重试；cancel 当前请求终止、后续跳过、已有建议保留；partial 明示截断；no-op 同标签不写；stale 内容变化不保存；persisted 建议可重启复用；save 部分成功逐项标识且保留失败项。

## 验证范围

主进程测试覆盖手动确认、缓存键、已有标签合并、同名规范化、上限、内容过期、删除、取消、无重试、失败保留、路径/二进制约束、无源文件写入。
Renderer 覆盖默认选择、确认、修改建议、逐项失败/跳过/重试、局部保存。Electron 用隔离 Home 与 loopback 模拟 API 检查完整保存闭环、三语言与 920/1180/1440 的布局。模拟通过不代表所有真实 API 供应商兼容，也不发出真实付费请求。
