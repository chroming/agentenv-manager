## What's changed

- OpenCode now respects Skill source priority. A managed OpenCode copy correctly shadows lower-priority copies under Claude-compatible directories instead of producing false shared-Skill migration prompts or perpetual pending states.
- Profile Skill update status remains readable at the minimum supported window size.
- Skill update previews keep their impact summary, Agent-copy option, file changes, and actions in separate regions so long file lists no longer overlap the dialog header.
- Local Skills keeps decision states and their next actions in distinct columns, including `Needs decision` and `Choose version` at compact window sizes.
- Product contracts and desktop regression coverage now enforce portable Profile references, ordered Agent Skill roots, dialog containment, and responsive state/action spacing.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
