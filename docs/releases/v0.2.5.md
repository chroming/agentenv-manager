## 更新内容

- AI 摘要、标签和分析遇到部分格式异常时保留可用结果，保存失败可单独重试保存，不再次调用模型。
- Codex 的 Profile Skills 支持仅显式调用，与 Claude Code 使用相同的设置入口。
- 更新 Skill Library 时保留被外部修改的 Agent 副本，不再因此阻止整个 Library 更新。
- Worktrees 支持按仓库或当前筛选结果批量选择，清理时可在当前项完成后停止。
- 本地 Codex、Claude Code 和 Pi 对话支持预览后删除、立即撤销和从“最近删除”恢复。
- AI 服务支持 HTTP 地址，并更清楚地区分认证、额度、限流和连接错误。
- 更新 Electron 等依赖，修复已知高危安全问题。

## What's changed

- AI summaries, tags, and analyses retain usable results when part of a response is malformed; failed saves can be retried without another model request.
- Codex Profile Skills support explicit-only invocation through the same control used for Claude Code.
- Skill Library updates preserve externally changed Agent copies instead of blocking the entire Library update.
- Select eligible worktrees by repository or current filters, and stop cleanup after the current item finishes.
- Preview and delete local Codex, Claude Code, and Pi conversations, then undo immediately or restore them from Recently Deleted.
- AI services support HTTP addresses and distinguish authentication, quota, rate-limit, and connection errors more clearly.
- Update Electron and other dependencies to fix known high-severity security issues.

## Installation

Homebrew:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

也可以在应用内检查更新，或从本页下载安装包。直接下载的 macOS 应用需要先复制到 Applications、推出 DMG，再对已安装的应用确认“仍要打开”；升级后仍可能需要确认 Keychain 访问权限。

You can also check for updates in the app or download an installer from this page. For a direct macOS download, copy the app to Applications, eject the DMG, and approve Open Anyway for the installed copy; macOS may still request Keychain access after an update.
