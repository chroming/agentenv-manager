## 更新内容

- Worktrees 复用最近的扫描结果，切换页面不再重复全量扫描；重启后也可以直接分析缓存列表中的工作树，分析前会重新核对当前 Git 状态。
- 优化工作树的 AI 保留建议、仓库分组和忽略操作，让需要检查和可以清理的条目更容易区分。
- 统一本地与 SSH 设备的 Agent 选择和状态展示，精简常用操作按钮。
- 对话列表始终显示文件大小；切换排序时保留资源名称、来源和其他基本信息。
- 改进历史对话读取兼容性，以及工作区和刷新操作的缓存一致性。
- 修复部分运行时漏读多段压缩对话的问题；压缩历史不完整时保留缓存，不再误判为空记录。

## What's changed

- Reuse recent Worktree scans across navigation. Cached worktrees can be analyzed after a restart, with current Git state checked before analysis.
- Improve AI retention advice, repository grouping, and exclusion controls in Worktrees.
- Unify local and SSH Agent selection and status displays, and simplify routine action buttons.
- Always show conversation file sizes and preserve resource identity and basic metadata when changing sort order.
- Improve conversation history compatibility and cache consistency across workspace navigation and refreshes.
- Read concatenated compressed histories reliably and preserve cached history when compressed input is incomplete.

## Installation

Browser-downloaded macOS packages require Open Anyway approval. macOS may request permission to access the app's Keychain entry after an update.
