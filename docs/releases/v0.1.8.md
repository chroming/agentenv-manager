## What's changed

- Skill management now starts with a smaller local footprint and makes takeover choices explicit before changing an Agent.
- Local Skills can review the current Profile's Skills or all local copies, then automatically manage safe cases while leaving real conflicts for review.
- Shared `~/.agents/skills` copies now have a clearer keep, manage, or remove lifecycle without silently disrupting unsupported Agents.
- Legacy ownership records can be moved into AgentEnv's central data store, reducing management files inside Agent directories.
- Local Skill cleanup now ignores discovery-only plugin copies, reports unreadable locations without hiding healthy results, and verifies that cleanup actually converged before completing.
- Failed or stale cleanup operations remain open with an actionable explanation, and partially applied changes are rolled back.
- Agents can be reordered in Settings; the chosen order is used consistently throughout the app and persists on this device.
- Settings controls now use a consistent size and alignment. Backup cleanup defaults to 30 days, and Skill source checks default to once per day for new installations.
- Startup data migration no longer races with window-state persistence on slower filesystems.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages still require the first-install Open Anyway approval because they are ad-hoc signed and not notarized.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
