## What's changed

- Shared Skills now use a simpler control model: leave the shared folder as-is, let Library manage its shared copies, or explicitly move them to Profile control after preview and backup.
- Profiles only ask for shared-Skill migration when a shared copy actually prevents the intended on/off state. Managed shared copies no longer appear as perpetual pending changes.
- Local Skills Manager now uses one consistent set of states and actions for individual Skills and collection links, making the next step easier to understand.
- The macOS application menu and update status now follow the selected interface language, including update, restart, Settings, and diagnostics actions.
- Upgrade and packaged-app checks now cover production-shaped legacy data while preserving current Profiles, Library data, settings, sources, and recovery files.
- Profile Apply responsiveness checks are now deterministic on slower release runners.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
