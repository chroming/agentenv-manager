## 更新内容

- 新增独立 Worktrees 页面，无需添加 Workspace 就能扫描常用目录，查看分支、未提交修改和占用空间，并预览、清理和恢复工作目录。
- Worktree 清理支持按仓库选中符合批量清理条件的条目，展示单项大小、总大小和预计释放空间，完成后立即更新列表。
- 加快 Worktree 扫描与清理，避免遍历仓库内全部源码，并修复普通目录触发 Git 警告、取消扫描被误报为错误的问题。
- 统一 Skills、来源、Groups、Instructions 和 Conversations 的搜索、筛选与排序入口，记住排序选择，并显示排序对应的信息。
- 加快多 Agent 共用 Profile 时的状态读取和 Instruction 引用检查，备份删除后不再等待整个备份列表刷新才恢复操作。
- 统一列表、按钮和远程信息的文字样式，更新中英文 README 与演示截图。
- 更新 Electron 和相关依赖的安全补丁。

## What's changed

- Add a dedicated Worktrees page to discover common folders without adding a Workspace, inspect branches, uncommitted changes, and disk usage, and preview, remove, or recover working directories.
- Select batch-cleanup-eligible worktrees by repository, review individual and total sizes plus estimated freed space, and see confirmed removals immediately in the list.
- Speed up worktree discovery and cleanup without crawling all tracked source files, avoid Git warnings for ordinary folders, and treat cancelled scans as cancellation rather than errors.
- Unify search, filter, and sort controls across Skills, sources, Groups, Instructions, and Conversations, remember sort choices, and show the matching metrics.
- Speed up status reads for Profiles shared by several Agents and Instruction usage checks, and keep backup actions responsive while the inventory refreshes after deletion.
- Normalize typography in lists, buttons, and remote details, and refresh the bilingual README and demo screenshots.
- Update Electron and related dependencies with security patches.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

You can also check for updates in the app. Browser-downloaded macOS packages require Open Anyway approval. macOS may request permission to access the app's Keychain entry after an update.
