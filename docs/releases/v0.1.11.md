## What's changed

- Codex is now detected through the current ChatGPT desktop app on macOS, even when a standalone `codex` command is not installed. AgentEnv can use the app's bundled Codex runtime for supported workflows while continuing to present a single Codex Agent.
- Shared Skill folders now explain when they prevent a Profile from controlling individual Skills. Apply previews provide a direct, warning-level path to review and move those shared copies into Agent-specific managed locations.
- Profiles, Workspaces, Agent status, and the sidebar now share consistent text columns and compact status wording across supported window sizes and languages.
- Electron UI tests now wait for asynchronous state changes more reliably, reducing false failures in release validation.
- macOS Keychain guidance now reflects the stable application identity used by current packages.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
