## 更新内容

本次包含未成功发布的 0.1.22 全部更新。

- SSH 工作区：浏览远程目录、管理项目资源，并从统一工作区列表和 Quick Open 打开。
- AI 辅助：手动生成 Skill 更新摘要、建议标签，以及分析 Profile、运行对比和重复 Skill。结果可保存复用，功能可在设置里关闭。
- Skills：统一列表、来源和分组的筛选、状态与更新入口；来源新增 Skill 可先预览内容再添加。
- 标签：区分固定标签与 AI 建议，增加独立标签列，改进长标签和溢出显示。
- 修复 AI 摘要分类解析失败，改善 AI 服务配置、连接测试和操作反馈。
- 修复非悬浮滚动条下 Skill Group 与成员开关错位的问题，补充多尺寸回归测试。
- 更新有安全告警的构建依赖，并更新中英文 README 和演示截图。

## What's changed

Includes all changes from 0.1.22, whose release did not complete.

- Browse SSH workspace folders, manage project resources, and open remote workspaces from the shared list or Quick Open.
- Generate Skill update summaries and tag suggestions manually. Analyze Profiles, comparison results, and duplicate Skills. Saved results can be reused; AI features can be disabled in Settings.
- Use consistent filters, status actions, and update controls across Skill list, sources, and groups. Preview new source Skills before adding them.
- Distinguish fixed tags from AI suggestions, with a dedicated tag column and clearer overflow handling.
- Fix summary category parsing failures and improve AI connection testing and progress feedback.
- Align Skill Group and member switches when scrollbars take up layout space, with regression coverage across window sizes.
- Update build dependencies affected by security advisories and refresh both READMEs with current demo screenshots.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use Settings > General > App updates. Browser-downloaded macOS packages are not notarized and require Open Anyway approval. macOS may also ask for permission to access the app's Keychain entry after an update.
