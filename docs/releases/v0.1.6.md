## What's changed

- Direct macOS installations can now download, verify, and install updates from Settings when the app is in a writable Applications folder.
- Direct updates verify the official ZIP, version, bundle identity, and code seal before replacing the app. If the new version does not confirm startup, AgentEnv restores and reopens the previous version.
- Homebrew upgrades now preserve the directory containing the running app, including per-user `~/Applications` installations, instead of falling back to `/Applications`.
- The README and product screenshots now match the current Agents, Profiles, Skills, Workspaces, Compare, and Conversations interfaces.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages still require the first-install Open Anyway approval because they are ad-hoc signed and not notarized.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
