## What's changed

- Profile changes now save automatically inside AgentEnv without changing an Agent until Apply.
- Profiles can restore the version from the last successful Apply, and recent Profile edits remain available from Recovery.
- Workspace Instructions now use the same readable preview and editor as Profiles, with recovery records for explicit file changes.
- Agent, Profile, and Workspace order and the most recently selected items now persist on this device.
- Refresh, update, and background actions use consistent progress feedback without moving stable lists, and Conversations show the time of the latest reply.
- Historical Skill source-merge archives no longer block current Library changes as unfinished recovery work.
- The README and mock screenshots now match the current Profile and Workspace workflows.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages still require the first-install Open Anyway approval because they are ad-hoc signed and not notarized.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
