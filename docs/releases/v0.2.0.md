## 更新内容

- Claude Code：Profile 中的 Skill 可设为仅手动调用，保留主动引用入口，不让模型自动调用；不会修改 Library 原文件。
- 对话：改进本地和 SSH 历史发现及部分读取失败的处理，开启索引时保持设置可操作。对话来源和终端设置移到独立的 Conversations 分类。
- 界面：精简重复说明和次要操作，修复 Skills 列表对齐与详情弹窗的浮动提示；侧栏用图标分别显示本地和远程 Agent 数量。
- 性能：减少启动时对历史备份和已迁移 Profile 的重复处理，改善侧栏收放及 Agent 刷新时的操作体验。
- 安装：修复新版 Homebrew 的安装钩子弃用警告，保留原有安装目录和 quarantine 处理逻辑。

## What's changed

- Set Claude Code Profile Skills to manual-only invocation without changing the Library originals.
- Improve local and SSH history discovery and partial-read handling. Keep indexing controls responsive, and move conversation sources and terminal settings into a dedicated Conversations category.
- Reduce repeated text and secondary controls, fix Skill list alignment and floating hints in detail dialogs, and distinguish local and remote Agent counts with icons in the sidebar.
- Reduce repeated startup work for historical backups and migrated Profiles, and improve sidebar and Agent refresh interactions.
- Fix the deprecated installation hook warning in newer Homebrew versions while preserving installation-directory and quarantine handling.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use Settings > General > App updates. Browser-downloaded macOS packages are not notarized and require Open Anyway approval. macOS may also ask for permission to access the app's Keychain entry after an update.
