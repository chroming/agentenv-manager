## What's changed

- Fixed a Profile state issue where an Agent could already match the selected Profile while the interface continued to show `Apply pending` and Preview reported no changes.
- Shared Skill cleanup progress is now evaluated separately from Skills that are already active in an Agent, avoiding false pending states during gradual migration.
- A no-change Apply now refreshes the Agent state immediately instead of leaving stale status in the interface.
- Profiles now show the same deployment summary in both the selector and the selected Profile details, including Profiles active on multiple Agents.
- Profile and Workspace headers now share the same structure, spacing, Agent context, primary-action placement, and responsive behavior.
- Single-Agent contexts are displayed as plain context instead of looking like disabled dropdown buttons.
- Shared button sizing and label alignment are enforced more consistently across Profile actions and Skill update dialogs.
- Diagnostics now include the lifecycle facts needed to investigate Preview and Apply state disagreements.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages still require the first-install Open Anyway approval because they are ad-hoc signed and not notarized.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
