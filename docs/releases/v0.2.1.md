## 更新内容

- 新增 WorkBuddy 支持：检测桌面安装，捕获和管理用户 Skills，加入专属图标。
- Agent 的启用、排序、检测偏好和高级路径配置统一放到 Agents 页面，移除设置中的重复入口。关闭 Agent 与停止接管保持独立。
- 捕获 Profile 时，Agent 内置和插件提供的 Skills 单独展示名称与路径，不再混入可移植资源或误认为已被接管。
- 修复 WorkBuddy 捕获时读取 SingletonCookie 等运行文件导致失败的问题，缩小其他 Agent 的捕获读取范围，复用运行时扫描结果。
- 改善 Agent 诊断、恢复状态提示和空 Instructions 展示，修复小窗口下的按钮与弹窗布局。
- 调整对话记录的消息排版，改善历史浏览时的阅读层级。
- 更新中英文使用说明和演示截图。

## What's changed

- Add WorkBuddy desktop detection, user Skill capture and management, and its own icon.
- Bring Agent selection, ordering, discovery preferences, and advanced paths together on the Agents page. Turning an Agent off remains separate from stopping management.
- List Agent-provided Skills separately during capture, including names and paths, without importing or taking ownership of them.
- Fix WorkBuddy capture failures caused by volatile runtime files such as SingletonCookie. Narrow capture reads across integrations and reuse runtime inventories.
- Improve Agent diagnostics, recovery guidance, empty Instructions, and compact-window layouts.
- Refine message layout and reading hierarchy when browsing conversation history.
- Refresh the English and Chinese documentation and demo screenshots.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

You can also check for updates in the app. Browser-downloaded macOS packages require Open Anyway approval. macOS may request permission to access the app's Keychain entry after an update.
