## 更新内容

- 对话搜索：可主动开启本地和 SSH 设备的历史索引，按设备暂停或关闭，在结果中查看对话来自哪台设备、哪个目录。
- 对话读取：改进历史发现和不完整扫描的处理，减少漏读；某个来源读取失败时保留已有结果。
- 界面：精简重复标题、状态说明和工具栏，将次要操作收进对应菜单。统一 Skills 列表、来源和分组的布局，改善小窗口下的对齐与展开区域。
- Profiles：增加刷新入口，修复展开资源或加载内容时工作区高度跳动。
- Skills：损坏的单条记录不再拖累整个列表；加强内容哈希、修改前校验和失败恢复，避免覆盖预览后发生的外部改动。
- 启动：加快大量 Skills 的哈希格式迁移，保留逐项校验和失败重试。

## What's changed

- Opt in to local and SSH conversation indexing. Pause or disable it by device, and see which device and directory each conversation came from.
- Improve history discovery and preserve existing results when a source cannot be fully read.
- Reduce repeated headings, status text, and toolbar clutter. Align Skill list, source, and group views, with fixes for small windows and expanded sections.
- Add Profile refresh and prevent the workspace from changing height when resources expand or load.
- Keep individual damaged Skill records from disrupting the whole list. Strengthen content hashing, pre-write checks, and recovery to protect changes made outside AgentEnv after a preview.
- Speed up hash-format migration for large Skill libraries while retaining per-item validation and retry handling.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use Settings > General > App updates. Browser-downloaded macOS packages are not notarized and require Open Anyway approval. macOS may also ask for permission to access the app's Keychain entry after an update.
