## What's changed

- Skill Groups now stay synchronized with their Library membership, support custom icons, and can be added to Profiles or copied into Workspaces through the same picker.
- Large Skill Groups scroll within the expanded group, and removing an already disabled group no longer creates a false Apply-pending state.
- Instruction Library entries show the Profiles that use them. Deleting a referenced Instruction now previews the impact, backs up the Instruction and affected Profiles, removes their references, and restores the previous state if any step fails.
- Workspace Skill batches are applied as one recoverable operation. A failed copy restores every earlier item from that batch.
- Remote Linux Agent snapshots can safely materialize valid in-home symbolic links while rejecting broken, cyclic, or outside-home links with the affected path.
- Skill source versions, Agent detection, Backup actions, Conversation working directories, and Profile resource controls use clearer and more consistent status presentation.
- Cross-platform Target conformance checks now use the same bounded timeout on Windows, macOS, and Linux.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
