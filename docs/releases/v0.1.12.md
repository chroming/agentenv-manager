## What's changed

- Actions across Agents, Conversations, Skills, and Settings now use a more consistent hierarchy, sizing, and loading treatment. Existing Agent lists stay in place during refresh instead of shifting behind a large status banner.
- Skill update results are clearer in both Library views and Profiles. An available update can be opened directly from its status, without a separate competing action button.
- The Update All dialog now keeps rate-limit and other preparation failures in the normal scrollable layout, so error details no longer overlap the Agent-copy option at compact window sizes.
- Bulk Skill update controls now use the same progress and completion patterns as the rest of the desktop app, including consistent icon alignment and dialog structure.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
