## What's changed

- Profiles received through Workspace Sync now appear in the Profile picker without restarting AgentEnv Manager.
- Packaged builds expose the standard Developer Tools shortcut (`Ctrl+Shift+I` on Windows and Linux, `Option+Command+I` on macOS) so failures can be inspected on the affected device.
- Renderer-process failures now record the Chromium exit reason and exit code in startup logs and exported diagnostics.
- The packaged cross-platform regression now opens the OpenCode Profile capture review; a focused Renderer regression also covers the empty-resource and preserved-setting state reported on Windows.

## Windows capture issue

This release improves diagnostics and regression coverage for the reported white screen after reviewing an OpenCode capture. The available report does not yet identify the underlying Windows Renderer failure, so this release does not claim that root cause is fixed. If it happens again, export diagnostics or share the new `renderer-process-gone` entry with its `reason` and `exitCode`.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
