## What's changed

- Added native support for **Antigravity App** desktop application target integration with isolated configuration, skill management, conversation indexing, and safe static bundle inspection.
- Fixed Antigravity App target discovery so that opening AgentEnv Manager does not launch the Antigravity desktop GUI on startup.
- Cross-agent conversation continuation and handoff prompts allow direct continuation in supported agents or copying structured handoff contexts to other tools.
- Native conversations can now be safely relocated between workspace folders.
- Distinguish Profile content and explain AgentEnv state changes clearly in Apply previews.

## Update

Homebrew users can update with:

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

Direct installations can use `Settings > General > App updates`. Browser-downloaded macOS packages are not notarized and require the first-install Open Anyway approval.

Direct installers for macOS, Windows, and Linux are attached to this Release after the native build and packaged-app checks complete.
