## 更新内容

- **工作树清理**：可手动多选需要确认的工作树，再批量移到回收站或永久删除。自动全选仍只选可安全清理的项，不必等空间统计完成才能操作。
- **回收站**：支持一键清空。永久删除可停止；单项超时或未删完时，剩余文件留在回收站，可稍后重试。
- **保存与刷新**：Profile、Skill、工作区或恢复操作成功后立即显示结果。后续刷新失败时会单独提示，可重试刷新，不必重复操作。
- **SSH 设备**：设备离线时也能添加记录或改名，连接失败会在设备旁显示，并可单独重试。
- **AI 分析**：更清楚地区分空响应和其他服务错误，保留之前的分析结果，不自动再次请求模型。

## What's changed

- **Worktree cleanup**: Manually select worktrees that need review, then move them to Trash or delete them permanently in one batch. Automatic selection still picks only safe candidates, and you can act before size estimates finish.
- **Trash**: Empty Worktree Trash in one step. Permanent deletion can be stopped. If an item times out or cannot finish, its remaining files stay in Trash so you can retry later.
- **Save and refresh**: Profile, Skill, Workspace, and restore operations show their results as soon as they succeed. If the view fails to refresh, retry the refresh without repeating the operation.
- **SSH devices**: Add or rename a device while it is offline. Connection errors appear next to the device and can be retried separately.
- **AI analysis**: Empty responses are distinguished from other service errors. Previous results are kept, and no new model request is sent automatically.

## Installation

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

也可以在应用内检查更新，或从本页下载安装包。macOS 直接下载版请先把应用复制到 Applications、推出 DMG，再对已安装的应用确认“仍要打开”。升级后，macOS 仍可能要求确认 Keychain 访问权限。

You can also check for updates in the app or download an installer from this page. For a direct macOS download, copy the app to Applications, eject the DMG, then approve Open Anyway for the installed copy. macOS may still request Keychain access after an update.
