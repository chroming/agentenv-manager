## 更新内容

- 修复 Antigravity App 的 Skill 部署目录，旧目录中的安装记录会提示重新应用 Profile。
- Worktrees 的仓库全选只选择符合批量清理条件的条目，需要检查的工作树可手动生成 AI 保留建议。
- 加强 Worktree 清理前的状态检查，预览后有新修改、提交或仓库状态变化时停止清理，保留本地分支和代码历史。
- 统一代码、路径和 Diff 的等宽字体，修正 Skill 移除弹窗的可访问名称，将备份筛选中的同步名称统一为设备同步。
- 更新构建依赖的安全补丁。

## What's changed

- Fix the Skill deployment folder for Antigravity App and prompt Profiles with old installation records to be applied again.
- Repository-wide Worktree selection now includes only batch-cleanup-eligible entries, with on-demand AI retention advice for worktrees that need review.
- Strengthen Worktree cleanup checks: stop if files, commits, or repository state change after preview, while preserving local branches and code history.
- Unify monospace fonts in code, paths, and diffs, align the Skill removal dialog's accessible name with its title, and use Device Sync consistently in backup filters.
- Update a build dependency with a security patch.

## Update

```bash
brew update
brew upgrade --cask chroming/tap/agentenv-manager
```

You can also check for updates in the app. Browser-downloaded macOS packages require Open Anyway approval. macOS may request permission to access the app's Keychain entry after an update.
