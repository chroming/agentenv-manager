# 本地与 SSH 对话历史搜索

## 功能准入

目标：用户明确选择来源后，在一个入口搜索本机及 SSH 设备已有的 Agent 对话，知道记录来自哪台设备、哪个 Agent、哪个项目目录。

历史文件归 Agent 所有。AgentEnv 只管理本机搜索缓存；搜索授权独立于 Agent 安装、启用、Profile 和设备管理授权。来源设置、索引与覆盖报告不进入 Workspace Sync、遥测或 AI 请求。

## 授权和状态

- 新旧安装都必须明确启用历史搜索。未配置时不扫描原始历史，旧缓存不参与搜索。
- 来源是设备、Agent、历史根目录及扫描类型的精确组合。新增 SSH 设备不自动授权。
- 暂停停止采集，保留缓存搜索；关闭停止采集及搜索。默认清除关闭或移除来源的缓存，也可明确保留。
- 配置变更先取消运行中的任务并等待结束，再持久化和清理，禁止迟到结果重新写入。
- 启用后启动、页面刷新和每五分钟的后台检查增量索引。输入搜索词只查询本机数据库。
- 每个来源报告 pending/indexing/ready/partial/unavailable、发现/索引/失败/仅摘要数量及最后完整成功时间。
- 断线、数据库锁、格式不支持或部分文件损坏保留上次可信缓存。仅完整扫描才能删除确实消失记录的缓存。
- “已完成”仅代表所选已知目录的扫描完成，不代表找到机器任意位置的全部历史；额外目录由用户添加。

## 搜索与界面

Conversations 和 Settings 复用 `HistorySearchSettings`。授权弹窗复用 `ModalFrame`、`DialogHeader/Body/Footer`、`SettingsPreferenceRow`、`Switch`、`SelectControl`、`TextField`、`Button` 和 `IconButton`。不增加一级导航。

默认按设备显示开关，开启设备一次选择该设备的所有已知历史来源；关闭设备取消这些来源。单 Agent 的例外选择放在设备的更多菜单，部分 Agent 开启时设备仍显示开启。路径、单来源开关和覆盖报告通过菜单中的详情查看。暂停/恢复使用固定尺寸图标和悬浮提示，不随状态切换改变控件尺寸。上述修改点击保存后生效。

查询默认覆盖所有授权来源的标题、项目路径、用户/助手消息；工具记录需在筛选中明确打开。设备、Agent、项目及最近活动时间可以组合筛选。分页限制只限制返回条数，不限制搜索范围。

列表显示设备/Agent/时间和命中摘要，完整工作目录在详情可选择复制；来源详情包含连接、会话 ID、原始路径。远程记录不显示本地启动、续接或迁移入口。当前阶段只提供定位和复制，不恢复 SSH 会话。

额外历史目录也先保持搜索和阅读：仅凭历史文件位置不能可靠推断 Agent 的启动主目录，因此不展示原生启动或迁移入口。通过现有 Agent 配置根目录发现的本地历史继续使用原有原生操作。

## 支持与读取

- Codex/Trae CLI：rollout JSONL，包含归档；Codex 优先保留原生标题索引。
- Claude Code：projects JSONL，包括子 Agent 文件。
- OpenCode：只读 SQLite 事务读取已提交 WAL 数据和子会话；兼容旧版 JSON 文件。
- Pi：会话 JSONL，搜索保留分支消息；原生恢复继续使用 Agent 本身的会话语义。
- Antigravity：可读 transcript 和摘要数据库；只有摘要的记录必须标明，不得显示为全文搜索完成。
- SSH 使用系统 OpenSSH 和远端 Python 3 标准库，无远端安装、无远端缓存写入。缺少 Python 或无权限时在该来源展示可操作错误。
- 自定义运行目录需作为额外来源明确添加，不能猜测并遍历整个磁盘。目录外链接不跟随，循环不无限遍历。

## 证据要求

隔离 fake home 与假 SSH 覆盖未授权零采集、暂停、关闭、并发取消、旧缓存迁移、跨设备重名、部分错误、离线缓存、工具筛选、全局搜索和原始文件不变。Python 读取器用临时 SQLite/WAL 与 JSONL 实际执行验证。桌面 E2E 验证授权、检索、关闭及 920/1180/1440 尺寸、中英文布局和 Escape。

真实用户 SSH 设备不用于自动测试。测试通过不等价于验证了所有第三方 Agent 的未来格式。
