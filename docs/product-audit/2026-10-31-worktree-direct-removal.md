# 工作树直接移除

用户已判断目录不再需要时，清理意图不应被拆成“详情、提前勾选、生成预览、再次确认”。
核心任务仍是安全移除工作目录，不是跳过数据保护。

## 交互与边界

- 非批量候选但可人工清理的行，在原有动作列提供移除图标，点击直接生成最终确认页。
- 详情底部使用同一个“移除工作树…”动作，不再要求滚到底部提前勾选。
- 移除入口只读预览；最终红色移除按钮才授权执行。取消预览不会改原目录。
- 主目录、锁定、缺失、子模块、保留、忽略和不可读取项不获得此快捷入口。
- 自动全选依旧只含原有严格批量候选；不批量分析、不自动选择脏工作树。
- 脏内容仍走原有完整备份、内容与索引校验、过期复查、Git remove 和恢复事务。
- 行预览只在触发图标上显示进度，批量按钮和选择统计不跟着转圈或改变。

## 组件与布局

复用 IconButton、ResourceRow、ChoiceInput、DialogHeader/Body/Footer 及既有确认和结果页。
仅移除多余的前置确认控件；动作位用非交互布局槽居中，不改共享控件的尺寸、颜色和边框。
覆盖 920×620、1180×728、1440×900 与 en/zh_CN/zh_TW，保留滚动条安全区。

## 证据

- 新增回归先在旧实现上失败，证明之前没有列表直达确认入口。
- 166 项相关 domain/Renderer 测试通过，覆盖取消、失败、局部进度和十类不可直接移除条件。
- 隔离 Electron 在三语言中验证：列表预览 → 取消无变化 → 再次预览并确认 → 真实 Git 移除 → 恢复。
- 实际校验恢复的暂存文件、未跟踪文件、20 个实验文件和忽略文件，并逐字比较 Git 暂存/工作区状态。
- 当前构建身份 23e1ec62e723；已逐张检查九张受影响的工作树分析截图及最小中文列表。
- 确认页不再重复要求勾选，但仍明确提示脏文件的恢复副本与预计释放空间。
- 不修改后端清理规则，不推送或发布；本轮未执行 Windows/Linux 原生与安装包验证。

完成收据：构建、六项审计、166 项相关测试和三语言 Electron 流程通过；最终确认页在三档尺寸内可操作。
