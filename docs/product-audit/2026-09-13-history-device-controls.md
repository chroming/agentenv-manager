# 历史采集设备级控制

此前默认逐个列出 Agent 和路径，违背低负担授权流程。本次让设备成为默认配置单位，更多菜单提供单 Agent 选择，详情保留路径与覆盖信息。暂停/恢复复用固定尺寸 IconButton，不再显示按钮文字。

验证范围：组件测试覆盖整设备选择、菜单例外、保存、取消和失败保留；Electron 覆盖设备开关、菜单选择、暂停/恢复相同边界框、三种语言及 920/1180/1440 宽度。使用假 SSH 和隔离目录，不接触真实历史。

共享菜单增加可选 checked 语义；普通动作不变，选择项使用 menuitemcheckbox 并显示选中标记。不改变索引、权限和后台刷新契约。
