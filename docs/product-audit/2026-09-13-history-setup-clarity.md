# 历史搜索配置层级复查

## 问题与边界

此前只验证控件可用和边界，没有证明首次使用清晰。首次授权、运行控制、设备选择和缓存处理不应平铺为同级设置。

本轮只调整展示和命令时机：原始历史只读、显式来源授权、本机缓存及离线搜索边界不变。目标是先选择设备、再开启搜索；日常暂停立即生效，不清空正在阅读的对话。

## 共享组件与信息分配

- 未开启页使用 EmptyState，仅一个选择设备入口；隐藏不可用工具栏。
- ModalFrame、DialogHeader/Body/Footer 承担对话框布局；SettingsPreferenceRow 和 Switch 承担设备设置。
- IconButton 承担暂停、恢复及来源管理；ToolbarOverflowMenu 承担 Agent 例外与特殊目录入口。
- 设备详情只展示路径、覆盖和错误，移除重复开关与第二层折叠框。异常设备保留快捷详情入口。
- 缓存处理仅在移除既有来源或关闭功能时展示。

## 验收范围

覆盖未开启、首次配置、已开启、暂停、设备异常及详情展开截图；首次配置覆盖英文、简体中文、繁体中文和 920/1180/1440 宽度。来源选择取消无写入、暂停无需保存、搜索和清理后原始记录不变均由 Electron fake-home/fake-SSH 流程验证。

本轮不代表打包应用或真实 SSH 环境验收，不重跑已有全量测试债务。新增视觉基线必须结合实际截图审阅，不将基线更新本身视为质量证明。

结果：41 项相关组件测试及历史搜索 Electron E2E 通过，TypeScript、构建、翻译与 UI 契约审计通过。截图分别检查未开启、首次选择、日常设置及详情展开，控制加载结束后采集稳定状态。
