# 更新摘要输入与操作栏

## 变更契约

核心任务：帮助用户决定是否更新 Skill，兼顾行为变化、使用兼容性和具体风险，不提供安全认证。
风险 9/10、频率 6/10、信息密度 8/10、视觉表达 3/10、动效 2/10。

| 问题 | 负责层 | 本次修复 |
| --- | --- | --- |
| 按文件顺序装入输入、超限整文件丢弃 | summaryEvidence / summaryInput | 指令和执行文件优先，大块分片，风险线索辅助排序；明确标记部分覆盖 |
| 重复准备全部输入后才开始生成 | SkillSummaryReview / summaryInput | 逐项准备生成，复用绑定内容哈希的证据；缓存不绕过过期校验 |
| 摘要缺少用途上下文和覆盖清单 | summaryService / SummarySchema | 发送有限用途上下文、变更清单、脱敏 Diff；相同 Diff 引用复用，保存完整已选证据 |
| 为限制文字长度丢掉额外风险发现 | summaryService / SkillSummaryContent | 普通发现限制三项，额外风险与兼容性发现保留；默认三项，展开查看其余 |
| 重新生成按钮贴内容末尾 | AIReviewHeading | 总动作归总栏，单项动作归单项标题；复用 ResourcePanelToolbar、IconButton、Button |

状态覆盖：初始、缓存、生成、停止、配置缺失、429 失败保留旧结果、部分分析、单项/批量、重启读取。
不增加依赖，不修改 Skill、Profile 或 Agent。仅用户手动请求发送资料，不自动重试或隐式分块调用。
生成记录保存准备与服务请求耗时；没有对真实供应商速度或安全判断准确率做保证。
