# Desktop Density Review

## Scope and boundary

Improve scanning and spatial grouping in Skills, Agents, Instructions, Profiles,
Workspaces, Conversations and their detail dialogs. Persistence, ownership,
update selection, recovery, and Agent deployment behavior remain unchanged.

## Shared contracts

- Single-line catalog records use the compact row token (42px). Two-line source
  groups retain the default minimum (58px); content may grow rather than clip.
- Source and identity have separate width budgets. Long identities truncate with
  the existing full-text access; actions and status retain dedicated tracks.
- Group membership is expressed by disclosure and indentation, not a second
  table header or a full colored container. Manual groups and sources keep
  their distinct identities and commands.
- ResourcePanelToolbar owns compact action spacing in both Profiles and
  Workspaces. Short content has no forced panel height; long content retains
  bounded scrolling and a reserved scrollbar gutter.
- MasterDetailLayout owns bounded adaptive compact list width. Description and
  reference count must not compete for the same short list line.
- Settings surfaces fill the page, while form sections stop growing at 1040px.
  Controls align to that content edge, not an unrelated viewport edge.
- Idle bulk-update counts belong in the dialog header. Active/completed progress,
  failed previews, copy-impact choices and cancellation remain available.
- AI commands remain explicit and manual. A result section heading appears when
  there is a result, rather than repeating the command above an empty section.
- DetailList owns optional field actions beside their values. Important paths,
  timestamps and hashes remain selectable; metadata wraps rather than clips.
- All Agent Profile cells use one reading line. Unconfigured Agents show Configure;
  configured Agents show their Profile; pending/drift/override details use an inline
  status hint, and recovery retains Open Recovery. Local rows have no redundant
  This Mac header; remote device context belongs to the group.

## Evidence

Renderer tests cover initial/update/error/cancel states and unconfigured versus
recovery Agent summaries. Electron tests cover compact row containment and
bounded settings at 920/1180/1440 widths, paired catalog toolbars, Profile status
lanes, nested group scrolling, interface languages, and shared desktop geometry.
The mock capture suite exercises the same rebuilt artifact, including empty,
single, populated and expanded resource panels and update/cleanup dialogs.
Passing geometry is not visual approval: inspect generated screenshots separately.

## Follow-up: missed configured-Agent state

The initial captures used unconfigured Agents, so they did not approve the managed
Profile cell. User feedback reopened this finding. The shared summary now removes
the second lifecycle text row for local and SSH Agents, and the obsolete local
device band is removed. `keeps configured Agent Profiles on one line before and
after edits` applies a Profile in an isolated home, changes its Skills, verifies
the pending hint, and measures one-line containment at 920/1180/1440 widths.
Renderer tests retain explicit recovery actions and accessible state details;
the SSH endpoint test also rejects the extra local band.
