# Worktree 清理信息与滚动安全区

## 产品判断

核心任务是在保留未保存价值的前提下识别和清理本机工作树，而不是按年龄自动删除目录。
操作风险 9/10、使用频率 5/10、信息密度 7/10、视觉表达 2/10、动效 1/10。
保持既有桌面分组列表、工具栏与确认弹窗，不增加并列工具栏、彩色标签或默认说明段落。

核心任务 → 更容易判断待清理对象 → 不能把“旧”误作“安全” → 时间仅作参考，保留原安全条件。

用户筛选/勾选 → 实时清理预览 → 显式确认移除 → 沿用原有 Git 清理、备份和恢复。
查看、排序和筛选不写工作树，不触发额外扫描或网络请求。

## 信息与状态契约

- 日期来自现有 modifiedAt，即文件系统测量，不是扫描时间或最近 Git 提交时间。
- 排除根 .git，包含被忽略文件；未知/不完整测量保持不可用，不猜为零或当前时间。
- 无测量意义的主工作目录不重复展示两个“不可用”。其他未知日期保持明确标识。
- 每行保留名称、路径、日期/大小、状态和当前选择控件，完整分支在原详情中查看。
- 批量筛选与全选使用同一个 isBatchCleanupCandidate；dirty、锁定、忽略、主目录等保护不放宽。
- 全局全选仍覆盖当前筛选中折叠的仓库；改变筛选清空旧选择，不静默清理。
- 时间是只读辅助信息，清理仍重新检查 Git 和预览，失败/恢复语义不变。
