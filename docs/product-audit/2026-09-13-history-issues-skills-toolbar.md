# 历史异常与 Skills 工具栏

## 改动

历史来源不再把尚未产生历史的默认来源当作待处理错误。明确添加的目录或已经索引的历史后来消失仍保留错误与缓存，不能静默删除搜索结果。异常入口改为查看未读取历史，详情给出路径、原始错误、重试和排除 Agent 的动作；重试失败在弹窗内显示。

Skills 三种视图去掉普通筛选项的重复计数，保留更新数量。检查更新复用 SkillMaintenanceAction 的 IconButton，覆盖列表、来源、手动分组及 Profile；更新操作仍保留文字以区分查看与批量变更。没有缩小字号、删除表格列或把状态与动作叠放。
